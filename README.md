# Christopher Elijah — Professional Portfolio

A responsive personal/business portfolio website for Christopher Elijah and Everprof Computer World.

## Built with
- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- Google Fonts (Poppins + Inter)
- Font Awesome Kit

## Folder structure
```text
Portfolio/
├── index.html
├── README.md
└── assets/
    ├── css/style.css
    ├── js/script.js
    ├── images/mylogo.png
    └── gallery/*.svg
```

## Run locally
Open `index.html` in a modern browser.

The site uses CDN resources for Bootstrap, Google Fonts and Font Awesome, so an internet connection is needed for those external resources.

## GitHub Pages
Upload the contents of the `Portfolio` folder to your repository. The root `index.html` is ready for GitHub Pages.
